# 🧠 AI-Based Hallucination Detection using NLP

## 📌 Project Overview

This project is an **AI-based NLP application for detecting hallucinations in generated text**.

AI systems and Large Language Models can sometimes generate information that may not be supported by the given context or may contain incorrect information. This project aims to analyze generated text and identify possible hallucinated content using Natural Language Processing techniques.

The project provides Python-based scripts for hallucination detection and interactive checking.

---

## 🎯 Objectives

* Detect possible hallucinations in AI-generated text.
* Analyze text using Natural Language Processing techniques.
* Provide an easy way to check whether generated content is reliable.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/mahasophia/Hallucination--NLP-project.git
```

### 2. Open the project folder

```bash
cd Hallucination--NLP-project
```

### 3. Install the required packages

```bash

```
